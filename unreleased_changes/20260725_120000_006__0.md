* Feature : Support comparing two matched properties in a Cypher `WHERE`, e.g. `WHERE a.balance > b.balance`, as a top-level conjunct (ANDed). Supported with `=`, `<>`, `<`, `<=`, `>`, `>=`; a field-vs-field comparison nested inside `OR`/`NOT`, using a string operator, or combined with `DIFF` is rejected with a clear compile error.
