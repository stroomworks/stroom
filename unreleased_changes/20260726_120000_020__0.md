* Feature : Support `EXISTS { pattern }` and `NOT EXISTS { pattern }` correlated existence subqueries in a Cypher `WHERE` clause (e.g. `MATCH (p:Person) WHERE EXISTS { (p)-[:PARTY_TO]->(:Crime) } RETURN p.id`). The inner pattern is a single typed hop from a node bound by the outer `MATCH`, with optional target labels/properties; it filters each row by whether that adjacency exists at the query instant. `EXISTS` is now a reserved word.
