* Feature : Support scalar functions in a Cypher `RETURN`, evaluated over matched rows via Stroom's expression engine, e.g. `RETURN upperCase(a.name)`, `concat(a.first, ' ', a.last)`, `if(isNull(c.type), 'none', c.type)`. A curated allowlist of pure functions is exposed under their Stroom names (plus `toUpper`/`toLower` aliases); function arguments may now be property references. Unknown/withheld functions, and aggregate/`before()`/`after()` arguments, are rejected with a clear compile error.
