* Feature : Support label-only graph pattern matching without a property anchor (e.g. `MATCH (n:Person) RETURN n.id`, `MATCH (n:Person) WHERE n.age > 30 RETURN n.id`, and label-only patterns as traversal anchors). The engine scans the node store for nodes carrying the required label(s) rather than requiring a seekable property; results are never silently truncated (a scan matching more than the in-memory ceiling fails loud, asking for a property/WHERE/LIMIT).
