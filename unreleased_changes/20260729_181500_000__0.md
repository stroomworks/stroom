* Bug : With `stroom.query.optimiser.mode` set to `ON`, a `where` clause that mixed index-eligible and index-ineligible terms executed its terms with raw source text — so a quoted string was searched for including its quote characters, silently matching nothing, and an `in dictionary` term lost the dictionary it named. The automatic where/filter split now partitions the expression the legacy compiler produced, so every executed term is the legacy one, values and resolved dictionary references intact.
