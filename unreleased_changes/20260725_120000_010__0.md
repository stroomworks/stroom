* Feature : Add Cypher-exact function semantics alongside the Stroom-native functions, so both flavours are available in a Cypher `RETURN`. `substring(s, start, length)`, `left`, `right`, `size` and variadic `coalesce` now behave as openCypher defines them (e.g. `substring('hello', 1, 3)` is `'ell'`), and `ceil`/`toUpper`/`toLower` alias their Stroom equivalents. Stroom's own end-index `substring` remains reachable as `stroom_substring`. Implemented as a compile-time rewrite to Stroom's expression engine (no engine change); `replace` (regex-vs-literal) and list-returning functions such as `split` are deferred.
