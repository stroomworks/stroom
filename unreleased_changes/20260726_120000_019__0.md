* Feature : Support `UNION` and `UNION ALL` between Cypher graph queries (e.g. `MATCH (a:Account) RETURN a.id AS id UNION MATCH (d:Device) RETURN d.id AS id`). Branches are combined left-to-right; `UNION ALL` keeps duplicates, plain `UNION` de-duplicates by value. All branches must return the same column names (checked at compile time). `UNION` and `ALL` are now reserved words.
