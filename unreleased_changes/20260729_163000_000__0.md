* Bug : A graph ingest stream that fails fatally no longer ships the prefix of it that had already been written. Strict mode previously delivered records 1..N-1 to every node when record N failed, inverting its own "rather have no data than quietly incomplete data" contract — and because merge is a union of versions, mutations from the bad run then survived a corrected reprocess forever. Lenient mode is unchanged: a run that skips bad records still ships its fragment.
