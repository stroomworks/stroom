* Feature : Namespace Stroom-native Cypher functions under a `stroom.` prefix (e.g. `stroom.upperCase(a.name)`, `stroom.formatDate(a.ts)`, `stroom.substring(s, start, endIndex)`), reserving bare function names for Cypher-standard functions. The two flavours are clearly separated and cannot clash; a bare Stroom-extension name is now rejected with a hint to use the `stroom.` form. Replaces the interim `stroom_substring` with `stroom.substring`.
